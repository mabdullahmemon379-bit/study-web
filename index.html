Exercise 2.2 – Logarithmic Form, Exponential Form & Finding Unknowns
Fig: Q1 – Write in Logarithmic Form
1
Write the following in logarithmic form:
Ans.
📌 Rule: If am = N, then loga N = m
(i) 73 = 343
⇒ log7 343 = 3
(ii) 3−4 = 181
⇒ log3 (181) = −4
(iii) 10−3 = 0.001
⇒ log10 0.001 = −3
(iv) ∛(82) = 4
First, ∛(82) = 82/3 = 4
⇒ log8 4 = 23
Fig: Q2 – Write in Exponential Form
2
Write the following in exponential form:
Ans.
📌 Rule: If loga N = m, then am = N
(i) log27 81 = 43
⇒ 274/3 = 81
(ii) log2 (18) = −3
⇒ 2−3 = 18
(iii) log10 1 = 0
⇒ 100 = 1
(iv) log10 (0.01) = −2
⇒ 10−2 = 0.01
Fig: Q3 – Find the Value of Unknown
3
Find the value of unknown in the following:
Ans.
📌 Method: Convert to exponential form, then solve
(i) log32 x = 12
⇒ 321/2 = x
⇒ x = √32 = √(16 × 2) = 4√2
x = 4√2 ≈ 5.657
(ii) logx 3 = 12
⇒ x1/2 = 3
Squaring both sides: x = 32
x = 9
(iii) log√5 25 = y
⇒ (√5)y = 25
⇒ 5y/2 = 52
Equating exponents: y2 = 2
y = 4
(iv) log4 x = 32
⇒ 43/2 = x
⇒ x = (√4)3 = 23
x = 8
(v) log10 100 = y
⇒ 10y = 100 = 102
Equating exponents: y = 2
y = 2
(vi) logx 64 = 3
⇒ x3 = 64 = 43
x = 4
(vii) loga 1 = 0
⇒ a0 = 1
True for all a > 0, a ≠ 1
a = any positive number ≠ 1
(viii) log55 55 = y
⇒ 55y = 55 = 551
y = 1
(ix) log64 8 = x2
⇒ 64x/2 = 8
⇒ (82)<x/2 = 81
⇒ 8x = 81
Equating exponents: x = 1
x = 1
